# AI顧客・デザイナー対話練習アプリ

エンジニアがAIの顧客・デザイナー役と対話し、曖昧な要望の背景を探り、課題の仮説、解決策、受入条件をすり合わせる練習アプリの設計資料です。

現在は設計段階です。アプリの実装はまだ含まれていません。

## 設計資料

- [要件定義](requirements.md)：目的、設計思想、F-01～F-09の機能と受け入れ要件、4つのシナリオ。
- [詳細設計](detailed-design.md)：API、画面構成、状態遷移、T-01～T-16の受入テスト。

## 想定する体験

シナリオを選択し、必要に応じて自作の画像資料を添えながらAIと対話します。対話後に提案を整理して提出し、会話の根拠に基づくフィードバックを受け、再挑戦できます。

## 想定構成

Sitesのサーバー処理でAIを呼び出し、練習記録をD1、添付画像をR2に保存する設計です。利用者の認証、記録の所有者確認、画像内の命令を実行しない扱いを要件に含めています。
